## 功能展示

以下是目前支援的基本元素：

### 1. 段落
Word Engine 會把相連的文字解析為同一個段落，並且支援 `params.yaml` 中的對齊方式與縮排設定。

### 2. 無序列表
- 這是第一項

- 這是第三項

### 3. 有序列表
1. 第一步：載入 `refine.md`
2. 第二步：執行 QC 檢查
3. 第三步：渲染成 `.docx`

### 4. 程式碼區塊

```python
def hello_word_engine():
    message = "Welcome to Phase 1+2!"
    print(message)
```
